## For Claudes to come

**A tool's measured behaviour and its documented surface are different evidence classes — sample the first, fetch the second, and never generalise one into the other.** This session verified `deja --help` performs a literal search (true, measured) and shipped "no flags, no subcommands" (false — one `gh api .../readme` call would have shown `--re`, `--since`, `show`, `blame`). The subagent test passed because it exercised *routing to* the tool, not the *accuracy of claims about* it — a green orthogonal to the failure, verification.md's unearned-green shape in miniature. The correction cost a second publish; the prevention costs one API call before writing any interface claim about third-party code.

**External code in a key pipeline wants three things, and they compose:** a leash (the banc/session-search bench re-scores any new version in ~2 min), a doorbell (tube's weekly dev-tools timer files an infra bon on stable-tag drift — check-and-file, never auto-update), and a ritual (banc/session-search/README.md: pin → sumdb-verified build → dep+strace audit → bench). Zero-dependency Go binaries make the audit tractable: `go version -m` is the identity oracle (module stamp, not the binary's own `version` output, which lies on proxy builds), and a sudden dep tree appearing is itself the alarm. Learned live: check `go env GOBIN` before `go install` — on tube it points at `~/.local/bin` and overwrites the live binary in place, so any backup happens BEFORE, and clean pinned rebuilds replace `.bak` files as the rollback path.

**The session-search corpus is alive, and benches on it are echo-confounded within a day** — the eval-authoring session's own probes salt the transcript with every query term, and echo mass pushes original sessions below deja's result cap. Same-day before/after comparisons measure corpus drift as much as version drift; presence-drop on common-term tasks is a cap artefact until a `--limit 40` probe shows the expected id absent as a *header* (not as quoted excerpt inside someone else's result).
